<h1>🌟 Türkçe Karakter Destekli Python Modülü</h1>

<p>Python projelerinde Türkçe karakterleri doğrudan kullanmak bazen <code>UTF-8</code> uyumsuzluğuna veya <code>SyntaxError: Non-UTF-8 code</code> hatasına yol açabilir. Bu modül sayesinde tüm Türkçe karakterleri Unicode formatında güvenli bir şekilde kullanabilirsiniz. 🚀</p>

<h2>✨ Özellikler</h2>
<ul>
<li>✅ Tüm Türkçe karakterleri destekler: <strong>i, ı, ö, ü, ç, ğ, ş</strong> ve büyük harfleri</li>
<li>✅ Kod içinde <code>{i}</code>, <code>{ı}</code>, <code>{ö}</code> gibi yazdığınızda otomatik olarak doğru karaktere çevirir</li>
<li>✅ UTF-8 uyumlu ve Visual Studio 2022’de hatasız çalışır</li>
<li>✅ Kullanımı kolay: <code>import tr_char</code> ve <code>tr_char.tr("Merhaba {i}nsan")</code></li>
<li>✅ Profesyonel ve sürdürülebilir bir çözüm</li>
</ul>

<h2>💡 Örnek Kullanım</h2>
<pre>
import syntax-code

metin = "Merhaba {i}nsan, nas{ı}ls{ı}n? {c}ok g{ü}zel!"
print(tr_char.tr(metin))
# Çıktı: Merhaba insan, nasılsın? Çok güzel!
</pre>

<h2>📌 Neden Bu Modül?</h2>
<p>Python dosyalarında doğrudan Türkçe karakter kullanmak bazen hatalara sebep olabilir. Bu modül:
<ul>
<li>Her zaman güvenli ve Unicode uyumlu</li>
<li>Projeyi farklı IDE ve sistemlerde çalıştırırken sorun yaşamamanızı sağlar</li>
<li>Profesyonel projelerde sürdürülebilir ve temiz bir çözüm sunar</li>
</ul>
</p>
